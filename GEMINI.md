# ManyLives (remote MCP)

- `get_strategy_leaderboard` (free): top crypto strategies this week and month, ranked only on calls locked on the Base network before each period, with a luck check. The record starts 9 Oct 2026. General information, not financial advice.
- `find_paid_tools` (free): search 150+ pay-per-call tools (track records, point-in-time news, market data, web read/screenshot, AI, contract checks). Each result has a ready-to-run free trial call (3 a day per caller; some tools have no trial).
- `talk`: describe a job in plain words; the ManyLives Brain lists it and collects offers. Pay only after you verify the delivered work.

Paid tools are plain HTTP: call without payment to get HTTP 402 with the price (a US-dollar stablecoin on the Base network), then pay and call again. No account.
